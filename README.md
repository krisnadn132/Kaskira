# Krisna's Vault - Personal Financial Dashboard

Sebuah sistem dashboard keuangan pribadi minimalis berbasis web untuk mencatat transaksi fiat (pemasukan/pengeluaran), tabungan, serta portofolio aset kripto secara real-time.

## 🚀 Fitur Utama
- **Dashboard Ringkasan:** Total Net Worth (Kekayaan Bersih), Saldo Fiat, dan Tabungan.
- **Crypto Portfolio Tracker:** Riwayat jual/beli dengan penarikan harga live BTC, Fear & Greed Index, dan konversi kurs 1 USD ke Rupiah secara otomatis berbasis API.
- **Manajemen Transaksi:** Pencatatan pemasukan dan pengeluaran harian lengkap dengan grafik visualisasi.
- **Arsitektur Ringan:** Aplikasi halaman tunggal (SPA) murni menggunakan Vanilla JS tanpa framework berat, memanfaatkan `localStorage` untuk penyimpanan data aman di browser.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Custom Themes & Dark Mode), Vanilla JavaScript (ES6+).
- **Library & API:** Chart.js, CryptoCompare API, Exchange Rate API, Alternative.me API.
